## 3. S1 代码变更

### 3.1 新增 `kl1_dma_peer_to_peer()`

**文件**: `kunlun-driver/kunlun_module/kunlun/kl1/xpu_dma.c`

策略：仿 KL2 host-staging，放弃 SSE DMA 跨 PD：

```
src HBM ──EDMA(D2H)──► src bounce (1MB)
                          │ memcpy
                          ▼
                     dst bounce (1MB) ──EDMA(H2D)──► dst HBM
```

- 按 `(devfile_id, channel)` 排序获取 `wrch_sema` / `rdch_sema`，避免死锁
- 分片大小 `KL1_DMA_KBUF_SIZE` (1MB)

### 3.2 修改 P2P ioctl 路由

**文件**: `kl1/xpu_ioctl.c`

```c
// 前: dma_device_to_device_p2p()  → SSE DMA hang
// 后: kl1_dma_peer_to_peer()      → host-staging
```

### 3.3 头文件

**文件**: `kl1/xpu_drv.h` — 新增 `kl1_dma_peer_to_peer` 声明
